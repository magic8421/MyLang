## Work Done

### 1. Feature: `--xor-strings` compiler flag
- **Files:** `src/main.c`, `src/codegen.h`, `src/codegen.c`, `src/ast.h`, `src/runtime.h`, `src/runtime.c`, `AGENTS.md`
- Added an optional switch that encrypts every source string literal at compile time so the generated `.c` file never contains the original plaintext.
- Implementation details:
  - `src/main.c` parses `--xor-strings` and passes it to `codegen_program`.
  - `CodegenContext` stores `xor_strings` and `xor_str_id`.
  - `AstNode` got a `xor_str_id` field so each string literal maps to its pre-declared cipher array.
  - `codegen_collect_xor_strings` pre-scans the program and emits `static const uint8_t _xsN[]` top-level arrays in the generated C file before any function uses them.
  - `codegen_string_lit` emits `mylang_string_new_encrypted(MYLANG_TID_String, _xsN, len, key)` instead of `mylang_string_new(...)`.
  - f-string literal segments use `mylang_string_append_cstr_encrypted(acc, _xsN, len, key)`; empty accumulators use `mylang_string_new_encrypted(..., NULL, 0, 1)`.
  - Each non-empty literal gets a unique 8-bit key in the range 1..255.
- Runtime additions:
  - `mylang_string_new_encrypted(uint32_t type_id, const uint8_t* data, size_t len, uint8_t key)` decrypts the bytes into a `String` object.
  - `mylang_string_append_cstr_encrypted(String*, const uint8_t*, size_t, uint8_t)` decrypts a segment and appends it to an existing String.
